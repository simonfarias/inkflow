# InkFlow

Sistema de gestión para un estudio de tatuajes. Proyecto semestral de Fundamentos de Ingeniería de Software (FISO), USACH, segundo semestre 2026, vespertino.

## Integrantes

- Simón Farías
- Franklin Miranda

## Contenido

- docs/: entregables de cada laboratorio y entrevista con un tatuador
- src/: código del prototipo (desde el L5)

## Tecnología

Java 17, Spring Boot, Thymeleaf y PostgreSQL.
